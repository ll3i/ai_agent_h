# outpu1t_v7 / outpu1t_v8 결과 분석 요약

## 리더보드·평가 산식 (대회 기준)

| 항목 | 내용 |
|------|------|
| **평가 지표** | **Binary F1-Score** |
| **Public Score** | 전체 테스트 50% = **50개 이미지** (운영진 사전 샘플링), 대회 기간 중 실시간 공개 |
| **Private Score** | 전체 테스트 100% = **100개 이미지** 전체, 대회 종료 후 공개 |
| **1차 평가** | 대회 종료 시점의 리더보드 **Private Score** |
| **2차 평가** | 참가팀 전원 발표 평가 |

→ **최종 순위에는 Private Score(100장 기준 Binary F1)**가 사용됩니다.

---

## 분석에 쓴 기준

- **평가 지표**: Binary F1-Score (우선), 그다음 혼동행렬·Precision/Recall
- **정답**: `analyze_with_ground_truth.py`의 Ground Truth (TEST_000~TEST_099 순서, 100개)
- **클래스**: Normal=0, Abnormal=1  
- **혼동행렬**: (실제 → 예측)  
  - **TN**: 실제 Normal → 예측 Normal  
  - **FP**: 실제 Normal → 예측 Abnormal (False Alarm)  
  - **FN**: 실제 Abnormal → 예측 Normal (Missed Defect)  
  - **TP**: 실제 Abnormal → 예측 Abnormal

## 1. 리더보드 점수와 이번 분석의 관계

- 리더보드 **V8 ≈ 0.76**, **V7 ≈ 0.57**은 **Binary F1-Score**로 나온 값입니다.
- Public(50장) / Private(100장) 중 어느 구간 점수인지는 리더보드 표기에 따르면 됩니다.
- 아래 수치는 **프로젝트 내 Ground Truth**로 **전체 100장**에 대해 계산한 Binary F1 및 혼동행렬입니다.  
  운영진 공식 GT·샘플링과 다르면 프로젝트 기준 F1과 리더보드 수치가 어긋날 수 있습니다.

## 4. V7 vs V8 요약 비교 (동일 GT, 100장 기준)

**대회 메인 지표 = Binary F1-Score**

| 지표 | V8 | V7 |
|------|-----|-----|
| **Binary F1-Score** | **0.39** | **0.47** |
| Accuracy | 0.44 | 0.40 |
| Precision | 0.31 | 0.34 |
| Recall | 0.53 | 0.79 |
| **TN** | 26 | 13 |
| **FP (False Alarm)** | 40 | 53 |
| **FN (Missed Defect)** | 16 | 7 |
| **TP** | 18 | 27 |

- **리더보드**: V8 F1≈0.76, V7 F1≈0.57 → 공식 Public(50장) 구간일 가능성이 큼. 위 표는 프로젝트 GT로 100장 계산한 값.
- **V8**: TN↑, FP 상대적으로 적음. 대신 FN이 커서 **이상 놓침**이 많고, 이 GT 기준에선 F1이 낮게 나옴.
- **V7**: TP·Recall이 크고 FN이 적어 **이상 탐지**가 강함. FP가 많아 TN은 작지만, 이 GT 기준 Binary F1은 V7이 더 높음.

## 5. 재현 방법

- 스크립트: `analyze_v7_v8.py`
- 실행 후 `v7_v8_analysis_result.txt`에 상세 결과가 저장됩니다.
- Binary F1은 `sklearn.metrics.f1_score(y_true, y_pred)`로 계산됨 (이진 분류).
- Public 50장/공식 Private GT가 있으면 해당 id·레이블로 맞춘 뒤 같은 스크립트를 돌리면 리더보드에 가까운 F1·혼동행렬을 확인할 수 있습니다.
